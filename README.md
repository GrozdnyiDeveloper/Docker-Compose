# Примеры образов Docker Compose
В данном репозитории представлен примеры настроенных образов для развёртывания в Docker различных приложений с использованием конфигурации Docker Compose (многосервисная конфигурация)

**Архив имеет следующее содержимое:**
- time-app-praktika - Образ для запуска в Docker многосервисного приложения (REST API, база данных MySQL, веб-интерфейс для управления БД (Adminer) и фронтенд на Vue) с помощью Compose. Само приложение представляет собой виджет часов с CRUD-операциями по показу текущего времени, а также сохранению, загрузке и удалению времени в БД
- siteDocker - Образ для запуска в Docker многосервисного приложения (база данных PostgreSQL, веб-интерфейс для управления БД (Adminer) и веб-приложение на Go) с помощью Compose. Само веб-приложение представляет собой реализованную на Go информационную систему магазина канцелярских товаров с функционалом регистрации/авторизации, разграничения доступа/функционала по ролям, CRUD действиями над таблицами БД магазина (продукты, поставщики, акции и склады), сортировкой, поиском, фильтрацией, экспортом данных в CSV и сохранением сессий через Redis
